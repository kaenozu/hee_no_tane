# コンテンツリスク監査

## 目的

`content_review.dart risk`は、事実の正誤を自動判定するものではない。人手調査の順序を決める候補抽出であり、語句の一致だけで承認・否認しない。

旧分類では、`現在`だけで役職リスク、`心臓`だけで医療リスク、`紙幣`や`価格`だけで金融リスクと判定し、意味の異なる項目を混在させていた。この文書では分類の境界、重複検出、画像確認を定義する。

## リスク分類

- `numeric`: 数値、割合、概数を含む
- `dynamic_ranking`: 生産量、人口、価格、売上、シェアなど変動条件を伴う順位・最大最小
- `stable_comparison`: 地形、寸法、歴史上の比較など、直ちに現行値とは限らない比較表現
- `current_role`: `現在`等の時点表現と、首相・大統領・社長等の役職表現が同時にある
- `current_fact`: 現在・最新・今年等を含むが、役職者の特定ではない
- `human_health`: 病気、治療、薬、症状、診断、患者等の人の健康に関わる主張
- `biological_anatomy`: 心臓、血液、器官、細胞、遺伝子等の生物学・解剖学的主張
- `legal`: 法令、権利、義務、刑罰、税制等
- `financial_advice`: 投資、株式、為替、ローン、保険、年金、売買判断等
- `dynamic_price`: 価格、相場、時価、製造原価、費用等
- `currency_history`: 紙幣・硬貨・通貨の発行年、肖像、図柄、歴史等
- `duplicate_fact`: 問題文と説明の文字類似度から、同一事実を別IDで出題している可能性が高い

分類は重複し得る。例えば「現在の世界最大生産国」は`numeric`、`dynamic_ranking`、`current_fact`の候補となる。

## 重複候補

重複検出は、正答が同じ近似問題と、問題文・解説・カード本文が高い類似度を持つ組を抽出する。抽出結果の`duplicateQuestionIds`に相手IDを出力する。

これは同じ単語を含むだけで削除する機能ではない。人手で次を決める。

1. 完全な重複か、同じ題材の別事実か
2. 残す問題はどれか
3. 置換する問題のカテゴリ・難易度・画像は適切か
4. 両方を残す場合、学習価値の差が明確か

## 画像適合性

レビューCSVには、変更不可の`imageAsset`と人手判定用の`imageFit`を出力する。

`imageFit`の値:

- `unchecked`: 未確認
- `fit`: 本文を適切に表し、誤解を招かない
- `generic_placeholder`: 内容固有ではないが、本文と矛盾しない共通画像
- `replace_required`: 旧主張を図示している、または新本文と矛盾・誤認を生む

`imageFit`は監査注記でありJSONへ書き戻さない。`imageAsset`の変更はCSV承認フローでは禁止し、通常のコードレビュー対象として行う。

## 停止条件

- `current_role`を現職名の再検索なしで承認しない
- `dynamic_ranking`と`dynamic_price`は基準日・母集団・単位を固定する
- `human_health`、`legal`、`financial_advice`は直接資料を優先する
- `duplicate_fact`は残すIDと置換するIDを決めるまで承認しない
- `replace_required`の画像を残したまま本文だけ承認しない
- リスクタグがないことを正確性の証明として扱わない
