# 02_要件定義・仕様書

最終更新日: 2026年7月14日

## 1. プロダクト

**名称:** へぇのタネ  
**目的:** ユーザーが短時間で、出典を確認できる小さな知識に触れる機会を提供する。

## 2. 現行MVPの範囲

### 実装対象

- 初回オンボーディング
- 1日1問の日替わり四択クイズ
- 回答後の解説表示と関連カード獲得
- 獲得カード一覧、カード詳細、出典表示、共有
- 回答数、連続回答日数、カード閲覧数
- 端末内保存、テーマ設定、全データリセット
- Android、iOS、Web向けFlutterクライアント
- リポジトリ内のコンテンツ検証、出典監査、承認CSV

### 現行MVPに含めないもの

- アカウント、ログイン、クラウド同期
- バックエンドAPI、データベース、管理画面
- 広告、課金、サブスクリプション
- プッシュ通知
- ユーザー投稿、オンラインAIチャット、実行時AI生成
- 個人別レコメンド、関連カードグラフ

## 3. ユーザーとデータ

ユーザー種別は端末利用者のみとする。個人アカウントは作らず、進捗は`SharedPreferences`へ保存する。位置情報、連絡先、写真、マイク、健康情報は収集しない。

## 4. 主要画面

| 画面 | 要件 |
|---|---|
| オンボーディング | アプリの目的、1日1問、カード収集、統計を説明する |
| ホーム | 今日の問題状態、収集数、回答数、ストリーク、閲覧数を表示する |
| 日替わり問題 | 4択、回答ロック、解説、獲得カードを表示する |
| カード一覧 | 所有カードと未所有カードを区別して表示する |
| カード詳細 | 本文、承認済み出典、共有操作を表示する |
| 設定 | テーマ、法務情報、全データリセットを提供する |
| 起動エラー | 同梱データまたは保存データの読込失敗を明示する |

## 5. 機能要件

### F-001 日替わり問題

- ローカル日付ごとに安定した1問を選ぶ。
- 出題対象は、問題と関連カードの両方が公開条件を満たす組に限定する。
- 回答完了は日付、問題ID、カードIDの組で保存する。
- 日付変更やコンテンツ更新後に、別カードを回答済みとして表示しない。

### F-002 回答とカード獲得

- 選択後は多重回答を防止する。
- 正誤にかかわらず解説を表示する。
- 同日の同一問題への再試行は冪等とする。
- カード所有リストに同一IDを重複保存しない。

### F-003 カード閲覧と共有

- 未所有カードの本文は表示しない。
- カード詳細の閲覧だけで回答数やストリークを増やさない。
- 承認済みHTTPS出典だけを外部ブラウザで開く。
- 共有失敗、キャンセル、多重タップを安全に処理する。

### F-004 保存とリセット

- 保存更新をFIFOで直列化する。
- 保存、読込、削除の失敗を握りつぶさず、UIへ通知する。
- リセットは進行中の保存更新と競合しない。
- リセット後はオンボーディングとテーマを初期状態へ戻す。

### F-005 コンテンツ承認

- 問題文、4選択肢、正答位置、解説、カード本文、希少度、画像を監査対象とする。
- 承認対象の正規化内容からSHA-256を生成し、本文変更時は承認を無効化する。
- 画像レビュー状態、確認日、注記をJSONへ永続化する。
- 未承認、出典不一致、ハッシュ不一致、画像未確認の組は出題しない。

## 6. 非機能要件

| 項目 | 要件 |
|---|---|
| オフライン | 全主要機能が同梱データと端末内保存で動作する |
| 信頼性 | 不正JSON、空データ、参照切れを起動前またはCIで拒否する |
| セキュリティ | 秘密鍵やAPIキーをアプリへ同梱しない |
| プライバシー | サーバー送信を行わず、端末内データをリセット可能にする |
| アクセシビリティ | 操作要素をMaterialボタン/InkWell等で実装し、キーボードと意味情報を提供する |
| 互換性 | Android、iOS、主要Webブラウザで主要フローを確認する |

## 7. リリース条件

コード側は、コンテンツ検証、承認監査、Dart整形、静的解析、全テスト、Webビルド、Debug APK、Release AABのコンパイルをCIで成功させる。実機共有、配布署名、ストア申告、未承認コンテンツの人手確認は別途必要とする。
