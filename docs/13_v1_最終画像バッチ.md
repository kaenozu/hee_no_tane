## 正確な対象一覧の生成

PR #44統合後のmasterで次を実行し、現在の公開バンドルから対象IDを生成する。手書きの固定一覧を正本にしない。

```bash
jq -r '
  .entries[] |
  [
    .question.category,
    .question.id,
    .card.id,
    .card.title,
    .card.imageAsset,
    .card.imageReview.status
  ] | @tsv
' assets/data/content_bundle.json
```

件数と一意性の確認:

```bash
jq '.entryCount' assets/data/content_bundle.json
jq -r '.entries[].card.id' assets/data/content_bundle.json | sort | uniq | wc -l
jq -r '.entries[].card.imageReview.status' assets/data/content_bundle.json | sort | uniq -c
```

期待値:

```text
entryCount: 70
unique card ids: 70
generic_placeholder: 70（作業開始時）
```

## 各画像の作業

各カードについて次を実施する。

- [ ] カードの主張を正しく表す最終画像へ置換
- [ ] 文字、ロゴ、透かし、不要な記号がない
- [ ] 著作権、商標、肖像、建築物、商品画像の懸念がない
- [ ] AI生成の破綻、重複、意味不明な物体がない
- [ ] アプリ画面と1080×1350共有画像で切れない
- [ ] ファイル形式、解像度、アスペクト比が検証条件を満たす
- [ ] `imageReview.status`、確認日、確認メモを更新
- [ ] 必要な生成物とハッシュを再生成

## バッチ運用

- 1バッチ5〜10件を上限とする
- 画像差分と対応するカードIDだけをPRへ含める

- 目視確認前に`approved`へ変更しない
- 内容に疑義があれば`pending`または`correction_required`に戻す
