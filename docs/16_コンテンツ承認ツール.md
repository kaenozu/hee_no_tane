# コンテンツ承認ツール

最終更新日: 2026年7月12日

このツールは、問題と関連カードを1行にまとめたCSVを使い、構造化出典を人手で確認・反映するためのものです。事実確認そのものを自動化したり、未確認の項目を自動承認したりはしません。

## 1. CSVを出力する

```bash
dart run tool/content_review.dart export \
  --output build/content_review.csv
```

CSVの列は次の順序で固定されています。

```text
questionId,cardId,category,question,answer,explanation,sourceTitle,sourcePublisher,sourceUrl,verifiedAt,verificationLevel,reviewStatus,reviewNote
```

- `questionId`と`cardId`は変更禁止です。
- `category`、`question`、`answer`、`explanation`も照合用の固定項目です。
- `reviewNote`はレビュー作業用のメモであり、アプリのJSONには書き込みません。
- 現在の旧形式`sourceNote`は出典候補としてCSVへ表示されますが、それだけで承認済みにはなりません。

## 2. 人手で確認する

`reviewStatus`を`approved`にする前に、問題の正答・解説と関連カード本文の両方を同じ資料で確認します。

承認済みに必要な項目:

- `sourceTitle`: 正式な資料名
- `sourcePublisher`: 発行元・運営元
- `sourceUrl`: 直接根拠を確認できるHTTP(S) URL
- `verifiedAt`: `YYYY-MM-DD`形式の確認日
- `verificationLevel`: `primary`または`secondary`
- `reviewStatus`: `approved`

根拠不足の場合は`pending`または`rejected`のままにします。数値、ランキング、現職者、医療、法律、金融などの項目は、確認日現在の情報かを特に確認します。

## 3. 差分だけ検証する

```bash
dart run tool/content_review.dart import \
  --input build/content_review.csv
```

この実行はドライランです。次をすべて検証し、JSONへは書き込みません。

- CSVヘッダーと列数
- 全問題・全カードのID対応
- ID、カテゴリ、問題文、正答、解説が変更されていないこと
- 問題と関連カードの組み合わせが維持されていること
- URL、確認日、承認状態の構造が正しいこと
- `approved`の必須項目が揃っていること
- 問題と関連カードへ同じ出典を反映できること
- 反映後のコンテンツ検証と出典監査が成功すること

不正な行が1件でもある場合、両JSONは一切変更されません。

## 4. 検証済み差分を反映する

ドライラン結果を確認した後だけ、`--write`を付けます。

```bash
dart run tool/content_review.dart import \
  --input build/content_review.csv \
  --write
```

全行をメモリ上で検証した後、`questions.json`と`cards.json`を一時ファイル経由で置換します。問題と関連カードには同じ構造化出典を設定するため、承認済みURLの不一致を作りません。

反映後は必ず次を実行します。

```bash
dart run tool/validate_content.dart
dart run tool/audit_content_sources.dart
flutter analyze
flutter test
```

一般公開直前には次の厳格監査も成功させます。

```bash
dart run tool/audit_content_sources.dart --require-approved
```

## 5. 承認進捗を確認する

```bash
dart run tool/content_review.dart progress
```

カテゴリごとに、問題と関連カードの両方が承認済みでURLが一致している組数を表示します。

## 6. 高リスク候補を抽出する

```bash
dart run tool/content_review.dart risk \
  --output build/reports/content_review_risks.csv
```

キーワードと正規表現で次の候補を抽出します。

- 数値・割合・年代
- 最大、最小、世界一などのランキング表現
- 現職者や現在の役職
- 医療・健康
- 法律・制度
- 金融・投資

これは確認漏れを減らすための機械的な候補抽出です。抽出されなかった項目が安全または正確であることを保証しません。

## 7. アプリ内の出典リンク

問題とカードが人手確認済みで、カード側の構造化出典が`approved`の場合だけ、カード詳細画面に「出典を開く」を表示します。URL起動に失敗してもカード本文はそのまま閲覧できます。
