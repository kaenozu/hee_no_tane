# リリース判定

最終更新日: 2026年7月29日

## 現在の判定

**一般公開: 保留**

コード側の全レビュー指摘はPR #35で対応済みであり、承認済み70ペアの意味整合性監査と再発防止ゲートもmasterへ統合済みである。一般公開には、最終画像の人手承認、Android実機確認、配布署名、Play Console登録、ストア情報の確定が別途必要である。

一時除外していた23ペアは、官公庁、研究機関、専門機関、辞書の個別ページへ出典を置き換え、根拠箇所をレビュー注記へ記録した。断定が強かったサンドイッチのカード遊び逸話と「サボる」の説明も、直接確認できる範囲へ修正した。質問・カード・生成bundle・source hash・semantic reviewを同じ変更単位で再生成し、RC1の出題対象を承認済み70ペアへ戻した。

## 次のクリティカルパス

Android v1.0 RC1は次の順序で進める。

1. **P0 #24: 公開70カードの最終画像を確定する**
   - 70件すべてを最終素材へ置換する
   - 内容適合、文字・ロゴ、権利、不自然な生成物を目視確認する
   - `imageReview.status`を最終承認状態へ更新する
   - `validate_release_readiness.dart --require-final-images`を成功させる
   - RC1ポリシー適用後の70ペアを出題対象として凍結する
2. **P0 #23: 配布署名とPlay Console内部テストへ進む**
   - 本番keystoreを安全なローカル環境で作成する
   - 署名済みRelease AABをmasterから再現可能に生成する
   - Play Console内部テストへアップロードする
   - Pre-launch report、Data safety、コンテンツレーティング、ストア素材を確認する
3. **P1 #16: Android実機でカード共有画像を確認する**
   - RC1を実機へ導入後、PNG共有、共有キャンセル、連打防止、主要共有先での表示を確認する
   - P0/P1のクラッシュ、データ消失、共有不能が0件であることを記録する

署名作業は最終コンテンツ確定前にも準備できるが、内部テストへ投入するRC1成果物は#24完了後に作成する。先に署名済みAABを確定すると、画像差し替えによる再ビルド・再アップロードが発生するためである。

## 自動検証結果

GitHub Actionsで次を確認する。

- コンテンツ構造、manifest、承認済み出典、画像レビュー、SHA-256
- 承認済み70ペアの意味レビュー台帳、bundle hash、各ペアのcontent hash
- 一時除外リストが空で、RC1の出題対象が70ペアであること
- レビューCSVのexport/import往復とリスク抽出
- Dart整形、`flutter analyze`、全テスト
- Webビルド、Android Debug APK
- 短期CI署名鍵によるAndroid Release AAB
- CI署名鍵および`keystore.properties`の削除

## コード側で完了した項目

- 未承認、出典不一致、内容ハッシュ不一致、画像未確認の問題を出題しない
- 保存更新とリセットを直列化し、失敗をUIへ通知する
- 日次回答を日付、問題ID、カードIDで識別する
- 不正JSONと空コンテンツを拒否する
- 問題・全選択肢・解説・カード本文・画像レビューを承認対象にする
- レビュー注記とSHA-256を永続化する
- 承認済み70ペアの意味整合性を全件監査する
- 一時除外23ペアのトップページ・FAQ入口出典を直接根拠ページへ置き換える
- 意味レビュー台帳の欠落、未承認、ハッシュ不一致、確認漏れをCIで拒否する
- RC1の出題対象が70ペア以外になった場合は起動とCIを失敗させる
- 回答統計とカード閲覧統計を分離する
- キーボード、タップ、スクリーンリーダー向け操作を提供する

## 人間による確認が必要な公開ブロッカー

1. 公開70カードの最終画像について、内容適合、利用権、文字・ロゴ、不自然な生成物を確認する
2. Android実機で初回起動、回答、保存、再起動、リセット、共有を確認する
3. 配布用のAndroid署名鍵でAABをPlay Console内部テストへ登録する
4. Pre-launch reportのクラッシュ、ANR、互換性警告を確認する
5. プライバシーポリシーURL、サポートURLまたは連絡先を確定する
6. Data safety、年齢区分、スクリーンショット、ストア文案を実装と一致させる

Android v1.0先行公開では、iPhone、iPad、TestFlight、App Store Connect、Web本番ホスティングは別マイルストーンとし、Android公開のブロッカーにはしない。

## 判定基準

`docs/10_リリースチェックリスト.md`の自動検証がすべて成功し、RC1ポリシー適用後の70ペアが固定され、上記の人手ブロッカーが完了し、P0/P1の既知不具合が0件になった時点でAndroid v1.0を一般公開可とする。
