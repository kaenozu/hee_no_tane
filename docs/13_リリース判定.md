# リリース判定

最終更新日: 2026年7月14日

## 現在の判定

**一般公開: 保留**

コードで自動化できる修正と検証はDraft PR #35で完了した。一般公開には、実機、配布署名、ストアアカウント、人手コンテンツ確認が別途必要である。

## 自動検証結果

2026年7月14日のGitHub Actionsで次を確認した。

- コンテンツ構造、manifest、承認済み出典、画像レビュー、SHA-256
- レビューCSVのexport/import往復とリスク抽出
- Dart整形、`flutter analyze`、全テスト
- Webビルド、Android Debug APK
- 短期CI署名鍵によるAndroid Release AAB
- CI署名鍵および`keystore.properties`の削除

## コード側で完了した項目

- 未承認、出典不一致、内容ハッシュ不一致、画像未確認の問題を出題しない
- 保存更新とリセットを直列化し、失敗をUIへ通知する
- 日次回答を日付、問題ID、カードIDで識別する
- 不正JSONと空コンテンツを拒否する
- 問題・全選択肢・解説・カード本文・画像レビューを承認対象にする
- レビュー注記とSHA-256を永続化する
- 回答統計とカード閲覧統計を分離する
- キーボード、タップ、スクリーンリーダー向け操作を提供する

## 人間による確認が必要な公開ブロッカー

1. 未承認の問題・カード組について、主張、正答、全選択肢、解説、本文、出典を確認する
2. 各画像が対象内容に適合し、利用権を満たすことを確認する
3. Android実機で初回起動、回答、保存、再起動、リセット、共有を確認する
4. iPhone/iPad実機で主要フローと共有シート/ポップオーバーを確認する
5. Chrome、Safari、Edgeで共有またはPNGフォールバックを確認する
6. 配布用のAndroid署名鍵でAABをPlay Console内部テストへ登録する
7. TestFlightビルドを作成し、実機へインストールする
8. プライバシーポリシーURL、サポートURLまたは連絡先を確定する
9. Data safety、App Privacy、年齢区分、スクリーンショット、ストア文案を実装と一致させる

## 判定基準

`docs/10_リリースチェックリスト.md`の自動検証がすべて成功し、上記の人手ブロッカーが完了し、P0/P1の既知不具合が0件になった時点で一般公開可とする。
