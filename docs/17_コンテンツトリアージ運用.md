# コンテンツトリアージ運用

## 目的

未承認コンテンツを、出典URLを付けるだけの作業として扱わず、問題文・正答・解説・関連カードに含まれる主張を分解して評価する。

正答が妥当でも、解説やカードに誇張、俗説、条件不足、古い数値が含まれる場合は承認しない。

## 分類

- `approval_candidate`: 現行本文の全主張を採用可能な資料が支える
- `source_upgrade_required`: 本文はおおむね妥当だが、直接資料や確認年が不足している
- `correction_required`: 正答の一部は妥当でも、解説・カード・選択肢に修正が必要
- `replacement_required`: 問題の前提が曖昧で、一意の正答を維持できない
- `removal_candidate`: 根拠を確保できず、修正して残す価値も低い

## 主張の分解単位

各問題・カード組について、最低限次を別々に評価する。

1. 問題文の前提
2. 正答と選択肢の一意性
3. 数値、年代、順位、割合
4. 因果関係
5. 比喩や比較表現
6. 解説に追加された周辺事実
7. カード本文にだけ存在する追加事実

一つでも資料が支えない主張があれば、その組は`approved`にしない。

## 証拠の優先順位

1. 法令、官公庁、国際機関、公的統計
2. 査読論文、大学、研究機関、博物館、専門機関
3. 公式メーカー資料、業界団体、専門辞書
4. 信頼できる二次資料
5. その他のウェブ記事

Wikipedia、まとめ記事、検索結果の要約だけでは承認しない。候補資料を探す手掛かりとしてのみ使う。

## 資料選定ゲート

調査の長期化と取得不能な資料への固執を防ぐため、本文修正前に次を確認する。

1. 候補資料は原則3件までに絞る。
2. 候補ごとに、問題文・正答・選択肢・解説・カードのどこを直接支えるか記録する。
3. 現行値・順位・割合より、年次更新がなく条件を固定できる事実を優先する。
4. 公式原表、Flag、対象範囲を直接取得できない統計は、推測で補わない。
5. 取得不能な一次資料を同じ方法で反復せず、直接確認できる別事実への置換を検討する。
6. 確認済み、未確認、推測、反証、条件差を調査記録で分離する。

## メタ認知チェック

判断前に次を明示する。

- 自分が確認したのは正答だけか、本文全体か
- 資料が同じ対象・地域・年代・測定条件を扱っているか
- 数値が代表値か、単一個体・単一地点の記録か
- 相関を因果として説明していないか
- 有名な逸話を史実として扱っていないか
- 『世界一』『唯一』『ほとんど』『多く』などの範囲が定義されているか
- 現在値を扱う場合、確認年が固定されているか

## 停止条件

次の場合は自動的に未承認のまま停止する。

- 資料同士で主要数値が食い違う
- 問題の対象範囲が定義できない
- 一次資料が本文の一部しか支えない
- カードの追加表現だけ根拠がない
- 現在の選択肢では正答が一意にならない
- 医療、健康、法律、金融、安全に関する断定を二次資料だけで支えている

## 修正フロー

1. `review/content_triage_batch_*.csv`へ分類と理由を記録する
2. 候補資料を原則3件までに絞り、直接支えられる主張を比較する
3. 取得不能または条件不足の候補を棄却し、必要なら問題全体を置換する
4. 修正対象は小規模なバッチへ分ける
5. 修正文全文と調査記録を先に完成させる
6. 問題、カード、承認CSV、調査記録を同じ変更単位で更新する
7. 修正後の全文を資料と再照合する
8. JSON構文、ID対応、構造化出典をローカル検証する
9. コンテンツ検証、出典監査、Analyze、全テスト、Web、Androidを実行する
10. CI成果物の件数を変更前の期待値と照合する
11. PRとIssueを同期し、全ゲート成功後にのみマージ可否を別途判定する

## 第1バッチ

`review/content_triage_batch_1.csv`では、次の8組を先行評価した。

- シロナガスクジラの心臓重量
- 中国のリンゴ生産量と日本の消費
- アタカマ砂漠の無降水期間
- キリンの睡眠時間
- ジャイアントパンダの竹食
- エレベーターの閉ボタン
- sabotageと木靴の逸話
- 青色照明の心理・防犯効果

初期分類では、そのまま承認できる組はなかった。7組を`correction_required`、1組を`source_upgrade_required`として記録した。

### 第1バッチ修正完了

8組すべてについて、保持する主張を直接資料で確認できる範囲へ限定した。数値、順位、因果、俗説、標本の一般化、国・規格・研究条件の混同が残る場合は、現行問題を部分修正せず、直接検証できる問題へ置換した。

最後に残った`q_food_002` / `card_food_002`では、取得できないFAOSTAT原表への反復調査を停止した。世界生産順位・割合・日本流通の主張をすべて削除し、2010年のNature Genetics原著論文が系統再構築で栽培リンゴの祖先種を`Malus sieversii`と同定した結果へ差し替えた。

変更後の期待監査値は次のとおり。実数はCI成果物で再確認する。

- 承認済み: 42 / 206
- 要確認: 164 / 206
- 承認済み組: 21 / 103
- メタデータ不正: 0

第1バッチの初期分類CSVは調査開始時点の判断記録として保持し、完了した修正は`review/content_corrections_batch_1.csv`と各調査記録で追跡する。
