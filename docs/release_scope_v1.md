# v1.0 リリース範囲

最終更新日: 2026年7月16日

## 判定

**v1.0は広告あり・課金なしで公開する。**

AdMob導入に伴い、SDK、データ取扱い、プライバシー申告、テスト範囲をRelease AABと突合して確定します。課金はv1.0の対象外です。

## v1.0に含める機能

- 1日1問の日替わりクイズ
- 正誤にかかわらず解説表示
- 関連知識カードの獲得
- カード一覧（図鑑）・詳細・出典リンク
- カード画像共有（Web Share API / PNGフォールバック）
- 端末内保存、ストリーク、回答数、カード閲覧数
- 初回オンボーディング
- テーマ設定（ライト/ダーク/システム）
- データリセット
- プライバシーポリシー・サポート・バージョン情報
- Android、iOS、Web対応

## v1.0に含めない機能

- AdMob広告
- 広告除去買い切り課金（in_app_purchase）
- アカウント・ログイン
- クラウド同期
- プッシュ通知
- アナリティクス
- AI生成コンテンツ
- サーバー通信

## 公開対象コンテンツ

| 項目 | 件数 |
|------|------|
| 問題 | 103 |
| カード | 103 |
| 公開可能（承認済み） | 32 |
| 未承認 | 71 |

- コンテンツは `assets/data/` に同梱
- リリース前にリポジトリ上のレビュー工程で承認
- 承認後はSHA-256ハッシュで整合性を検証

## コンテンツ凍結ルール

1. リリース対象のコンテンツが承認済みであること
2. 承認後に内容が変更されていないこと（ハッシュ照合）
3. 未承認コンテンツはリリースセットから除外
4. CIで `validate_content.dart` が成功すること

## リリース前に残る人手作業

1. 未承認の問題・カード組について、主張、正答、全選択肢、解説、本文、出典を確認
2. 各画像が対象内容に適合し、利用権を満たすことの確認
3. Android実機で主要フロー確認
4. iPhone/iPad実機で主要フロー確認
5. Chrome、Safari、EdgeでWeb版確認
6. 配布用のAndroid署名鍵でAABをPlay Console内部テストへ登録
7. TestFlightビルドを作成し、実機へインストール
8. プライバシーポリシーURL、サポートURLを確定
9. Data safety、App Privacy、年齢区分、スクリーンショット、ストア文案を準備

## 判定基準

上記の人手ブロッカーがすべて完了し、P0/P1の既知不具合が0件になった時点で一般公開可とする。
