# へぇのタネ サポート

最終更新日: 2026年7月14日

「へぇのタネ」は、1日1問の四択クイズに答え、関連する知識カードを集めるアプリです。

## 対応プラットフォーム

- Android
- iPhone / iPad
- Web

実際に公開する対象OSバージョン、対応端末、対応ブラウザは、リリースビルドの実機確認後にストア掲載情報へ反映します。

## よくある質問

### 今日の問題が変わりません

日替わり問題は端末のローカル日付を基準に選ばれます。同じ日には、アプリを再起動しても同じ問題とカードの完了状態が復元されます。

端末の日付や時刻が正しく設定されていることを確認してください。日付を手動変更した場合、表示や連続回答日数が意図しない状態になることがあります。

### 回答後にカードが増えません

正誤にかかわらず、回答完了後に関連カードが獲得対象になります。次を順に確認してください。

1. 回答後の解説画面まで進んだか
2. カード一覧を開き直しても反映されないか
3. アプリを終了して再起動しても反映されないか
4. 端末の空き容量が不足していないか

改善しない場合は、下記の「不具合を報告するとき」を参照してください。

### データはどこに保存されますか

回答状況、獲得カード、閲覧数、連続回答日数、テーマ設定、オンボーディング完了状態は、端末内のアプリ保存領域に保存されます。現行バージョンでは、開発者のサーバーへの同期やバックアップは行いません。

端末変更やアプリ削除の前にデータを移行する機能はありません。

### データを削除したいです

設定画面の「データリセット」から、端末内に保存された本アプリのデータを初期化できます。

リセット対象には、回答状況、獲得カード、統計、テーマ設定、オンボーディング完了状態が含まれます。操作後の復元機能はありません。

OSのアプリ情報画面からデータを削除するか、アプリをアンインストールした場合も、通常は端末内データが削除されます。

### カード画像を共有できません

本アプリはカード画面からPNG画像を生成し、OSの共有機能へ渡します。次を確認してください。

- 共有先アプリがインストールされ、利用可能な状態か
- iPadでは共有ボタンを表示したまま共有シートを開いているか
- Webではブラウザが共有またはファイル保存に対応しているか
- 共有操作を連続で押していないか

共有をキャンセルした場合は、画像は送信されません。

### 出典リンクが開きません

カード詳細では、承認済みのHTTPS出典のみを外部ブラウザで開きます。通信環境、ブラウザの制限、リンク先の停止またはURL変更により開けない場合があります。

出典の内容に誤り、リンク切れ、表示上の問題がある場合は、カード名と表示されている出典名を添えて報告してください。

### オフラインで使えますか

クイズ、カード閲覧、統計、設定などの主要機能は、アプリに同梱されたデータと端末内保存で動作します。

外部の出典ページを開く操作と、インターネット上の共有先へ送信する操作には、通信が必要です。

### アカウントや課金はありますか

現行バージョンには、アカウント、ログイン、アプリ内課金、サブスクリプションはありません。広告表示にはGoogle AdMobを使用します。

## 不具合を報告するとき

次の情報を添えてください。個人情報、端末内の私的な画面、共有先の投稿内容は送らないでください。

- 発生日時
- アプリのバージョンとビルド番号
- 端末名
- OSまたはブラウザの名称とバージョン
- 発生した画面またはカード名
- 実行した操作手順
- 期待した結果
- 実際の結果
- 再現頻度（毎回、時々、1回のみ）
- 可能な場合は、個人情報を含まないスクリーンショット

## コンテンツの誤りを報告するとき

次の情報を添えてください。

- 問題文またはカード名
- 誤りと思われる箇所
- 根拠となる公的機関、研究機関、博物館等のURL
- 確認日

掲載内容は一般的な知識・娯楽を目的としており、医療、法律、投資その他の専門的助言ではありません。

## プライバシー

本アプリのデータ取り扱いは、`docs/store/privacy-policy-ja.md`を参照してください。公開時は、同じ内容をストアからアクセス可能な公開URLへ掲載します。

## お問い合わせ先

公開前に、次のいずれかの正式な窓口を確定します。

- ストア掲載用のサポートURL
- サポート用メールアドレス

確定後は、このページ、プライバシーポリシー、アプリ内の「プライバシーとサポート」、Google Play Console、App Store Connectに同一の窓口を掲載します。
