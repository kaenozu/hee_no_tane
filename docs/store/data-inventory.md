# へぇのタネ データインベントリ

最終更新日: 2026年7月14日
対象バージョン: `1.0.0+1`を基準とする現行MVP

## 1. 目的

本書は、アプリが扱うデータ、保存場所、利用目的、外部送信、削除方法、ストア申告上の扱いを一覧化する。

ストア提出時には、本書を提出対象commit、Release AAB、Xcode Archive、Webビルドおよび依存パッケージと照合する。

## 2. システム境界

現行MVPはローカル完結型のFlutterクライアントである。

- バックエンドAPI: なし
- 開発者管理データベース: なし
- アカウント: なし
- クラウド同期: なし
- 広告: Google AdMob（デバイス情報・広告識別子等をGoogleが取り扱う場合あり）
- 課金: なし
- 分析: なし
- クラッシュ収集: なし
- プッシュ通知: なし

主要データフロー:

```text
同梱JSON・画像 -> Flutterアプリ -> 画面表示
                              <-> SharedPreferences
カード画面 -> PNG生成 -> OS共有シート -> 利用者が選択した共有先
出典リンク -> 外部ブラウザ -> 承認済みHTTPSサイト
```

## 3. 端末内保存データ

保存キー: `hee_no_tane_save_data`
保存方式: `SharedPreferences`へバージョン付きJSONを保存

| フィールド | 型 | 内容 | 利用目的 | 保存期間 | 外部送信 | 削除方法 |
|---|---|---|---|---|---|---|
| `version` | int | 保存形式バージョン | マイグレーション、互換性 | リセットまたはアンインストールまで | なし | データリセット |
| `totalBrowseCount` | int | カード閲覧数 | ホーム統計表示 | 同上 | なし | 同上 |
| `totalPlayCount` | int | クイズ回答数 | ホーム統計表示 | 同上 | なし | 同上 |
| `streakDays` | int | 連続回答日数 | ストリーク表示 | 同上 | なし | 同上 |
| `lastPlayedDate` | string | 最終回答日 | ストリーク計算 | 同上 | なし | 同上 |
| `lastRewardDate` | string | 最終報酬日 | 報酬の重複防止 | 同上 | なし | 同上 |
| `lastDailyQuestionDate` | string | 日替わり問題の完了日 | 同日完了状態の復元 | 同上 | なし | 同上 |
| `lastDailyQuestionId` | string | 完了した問題ID | 日付変更・コンテンツ更新時の誤判定防止 | 同上 | なし | 同上 |
| `lastDailyCardId` | string | 対応カードID | 同上 | 同上 | なし | 同上 |
| `ownedCardIds` | string array | 獲得済みカードID | カード一覧・詳細の表示制御 | 同上 | なし | 同上 |
| `settings.themeMode` | string | system/light/dark | テーマ復元 | 同上 | なし | 同上 |
| `onboardingCompleted` | bool | 初回案内完了状態 | 起動時遷移 | 同上 | なし | 同上 |

### ストア申告上の扱い

上記データはアプリ機能上の利用状況またはゲーム進行に相当し得るが、端末内だけで処理し、開発者または第三者パートナーがアクセス可能な形で送信しない。現行実装ではGoogle Play Data safetyおよびApple App Privacyの「収集」に含めない。

|---|---|---|---|---|---|
| 問題 | `assets/data/questions.json` | 問題、選択肢、正答、解説、出典、承認情報 | いいえ | アプリ更新 | なし |

| フォント | `assets/fonts/` | Noto Sans CJK JP | いいえ | アプリ更新 | なし |

## 5. 一時データ

### 5.1 共有PNG

| 項目 | 内容 |
|---|---|
| 生成元 | カード共有プレビューの`RepaintBoundary` |
| 形式 | PNG |
| 生成場所 | アプリメモリ内のバイト列 |
| 渡し先 | `share_plus`を通じたOS共有シート |
| 開始条件 | 利用者が共有ボタンを押す |
| 開発者サーバー経由 | なし |
| 開発者による保持 | なし |
| 削除 | アプリ処理終了およびOS・共有先の管理に従う |

共有先サービスが画像、送信先、アカウント情報、IPアドレス等を処理する可能性があるが、それらは共有先の規約およびプライバシーポリシーに従う。

### 5.2 描画用画像オブジェクト

共有画像生成時に`ui.Image`を一時生成し、処理完了時に`dispose()`する。開発者サーバーへ送信しない。

## 6. 外部遷移

### 6.1 出典サイト

| 項目 | 内容 |
|---|---|
| 開始条件 | 利用者がカードの出典リンクを選択 |
| URL | コンテンツ審査で承認されたHTTPS URL |
| 表示方法 | 外部ブラウザ |
| アプリ内WebView | なし |
| 開発者による閲覧履歴取得 | なし |

外部ブラウザおよびリンク先サイトが処理するデータは、本アプリの管理外である。

## 7. 第三者パッケージ

`pubspec.yaml`で確認できるランタイム依存:

| パッケージ | 用途 | 本アプリから渡すデータ | 現行評価 |
|---|---|---|---|
| `shared_preferences` | 端末内保存 | 保存JSON | 端末内処理 |
| `share_plus` | OS共有シート呼出 | 利用者が共有するPNG | 利用者開始の外部共有 |
| `url_launcher` | 外部ブラウザ起動 | 承認済みHTTPS URL | 外部遷移 |
| `intl` | 日付・表示処理 | 端末内の値 | 端末内処理 |
| `crypto` | SHA-256検証 | 同梱コンテンツ | 端末内処理 |

提出時には、`pubspec.lock`で解決された全推移依存、Androidのマージ済みマニフェスト、iOS Privacy Manifestを確認する。SDKが独自に診断、広告、分析、識別子等を送信することが判明した場合は、本書とストア申告を更新する。

## 8. OS権限・機微データ

現行ソースで利用しないもの:

- 位置情報
- カメラ
- 写真ライブラリ
- マイク
- 連絡先
- カレンダー
- Bluetooth
- ヘルスデータ
- 金融・決済情報
- 通知

Androidソースマニフェストには`uses-permission`宣言がなく、iOS Info.plistには上記保護対象データの利用目的文字列がない。

ビルドツールまたは依存ライブラリが追加する非ランタイム権限を含め、最終的な権限一覧はRelease成果物から再確認する。

## 9. データ削除

### アプリ内削除

設定画面の「データリセット」は、SharedPreferencesの`hee_no_tane_save_data`を削除する。保存処理とリセットは同一FIFOキューで直列化し、古い更新がリセット後にデータを復活させる競合を防止する。

### OSによる削除

- Android: アプリ情報からストレージ消去、またはアンインストール
- iOS/iPadOS: App削除
- Web: サイトデータまたはブラウザストレージの削除

OSバックアップや端末移行による復元挙動は、OS設定とプラットフォーム仕様に依存するため、実機リリーステストで確認する。

## 10. 保存期間

開発者サーバー上の保存期間: 該当なし

端末内データは、利用者がデータリセット、OSによるストレージ消去、サイトデータ削除またはアンインストールを行うまで保持される。
