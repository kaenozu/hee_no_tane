# ストア開示整合性チェックリスト

最終更新日: 2026年7月14日
対象: へぇのタネ

## 1. 判定ルール

次の情報がすべて一致するまで、Google PlayまたはApp Storeへ一般公開しない。

- 提出する実バイナリ
- ソースコードと依存パッケージ
- アプリ内「プライバシーとサポート」
- 公開プライバシーポリシー
- 公開サポートページ
- Google Play Data safety
- Apple App Privacy
- ストア説明文、スクリーンショット、対象年齢

不明点が1つでもある場合は、推測で回答せず、Play ConsoleまたはApp Store Connect上では下書きとして保存し、実装・ビルド・SDK文書を再確認する。

## 3. 実装機能との一致

現行MVPの実装範囲:

- 初回オンボーディング
- 1日1問の日替わり四択クイズ
- 回答後の解説とカード獲得
- カード一覧、詳細、承認済み出典、画像共有
- 回答数、連続回答日数、カード閲覧数
- 端末内保存、テーマ設定、全データリセット

非実装機能:

- アカウント、ログイン、クラウド同期
- バックエンドAPI
- 広告、課金、サブスクリプション
- プッシュ通知
- 分析、クラッシュ収集
- ユーザー投稿、オンラインAI

確認:

- [ ] ストア説明に非実装機能を記載していない
- [ ] スクリーンショットに開発用画面、未実装画面、ダミー表示がない
- [ ] 「無料」「広告なし」「課金なし」等の表現が提出バイナリと一致する
- [ ] 「オフライン対応」は、外部出典とオンライン共有を除く表現になっている
- [ ] 「データは端末外へ出ない」と断定せず、利用者開始の共有と外部ブラウザ遷移を説明している

## 13. リリースブロッカー

次のいずれかに該当する場合は`release_blocked`とする。

- Data safetyまたはApp Privacyが実装と一致しない
- 公開プライバシーポリシーURLがない、または閲覧できない
- サポート窓口が未確定
- Release成果物の権限・SDK・通信先が未確認
- 子ども向け・年齢区分が未確定
- ストア説明またはスクリーンショットに未実装機能がある
- 収集・共有なしを裏付ける証跡がない
- P0/P1のプライバシー、データ消失、誤表示不具合が残っている
