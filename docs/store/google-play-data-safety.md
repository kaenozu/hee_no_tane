# Google Play Data safety 回答案

最終更新日: 2026年7月14日
対象: `へぇのタネ` 現行MVP
状態: **Play Console入力前の回答案。提出時にRelease AABと依存SDKを再確認すること。**

## 1. 結論

現行実装を前提とする推奨回答は次のとおり。

| 質問 | 回答案 |
|---|---|
| アプリは、申告対象となるユーザーデータを収集または共有しますか | **いいえ** |
| ユーザーデータを販売しますか | **いいえ** |
| 広告目的でデータを使用しますか | **いいえ** |
| アカウント作成機能がありますか | **いいえ** |
| アプリ内で端末内データを削除できますか | **はい。設定画面のデータリセット** |
| サーバー上のアカウントまたは利用者データの削除申請が必要ですか | **該当なし。開発者サーバーへ保存しない** |
| 独立したセキュリティレビューを受けていますか | **いいえ**（受審した事実が確認できるまで選択しない） |

Google Playでは、端末外へ送信されず端末内だけで処理されるデータは「収集」として申告不要とされる。現行実装の保存データは`SharedPreferences`内でのみ処理される。

## 2. 実装上の根拠

### 2.1 端末内保存

`SaveData`および`SaveRepository`は、次の情報をバージョン付きJSONとして`SharedPreferences`へ保存する。

- カード閲覧数
- クイズ回答数
- 連続回答日数
- 最終回答日、最終報酬日
- 日替わり問題の完了日、問題ID、カードID
- 獲得済みカードID
- テーマ設定
- オンボーディング完了状態

これらは開発者サーバー、分析サービス、広告ネットワークへ送信されない。

### 2.2 アカウント・広告・課金・分析

現行MVPには次の機能またはSDKがない。

- アカウント、ログイン、クラウド同期
- バックエンドAPI
- 広告、広告ID利用
- Google Play Billing、購入履歴
- Firebase Analytics、その他のアクセス解析
- Crashlytics等のクラッシュ収集
- プッシュ通知

### 2.3 権限

`android/app/src/main/AndroidManifest.xml`のソースには、位置情報、カメラ、マイク、連絡先、写真、通知等の`uses-permission`宣言がない。

ただし、最終申告はソースマニフェストだけでなく、Release AABから生成した**マージ済みマニフェスト**とPlay Consoleの権限表示を確認して確定する。

### 2.4 カード画像共有

本アプリは、利用者が共有ボタンを押した場合に限り、生成したPNGカード画像をOSの共有シートへ渡す。

Google PlayのData safetyガイダンスでは、利用者が明示的に開始し、データが共有されることを合理的に予期できる操作は「共有」の申告対象外となり得る。現行のカード共有はこの例外を適用する前提で、回答を「収集・共有なし」とする。

提出前に次を確認する。

- 共有対象がアプリ生成のカード画像のみである
- 端末の写真、連絡先、位置情報等を付加しない
- 共有先や送信相手を開発者が取得しない
- 共有処理が開発者サーバーを経由しない
- 共有画面とプライバシーポリシーに、利用者操作で外部サービスへ渡ることを明記している

### 2.5 出典リンク

カード詳細から、承認済みのHTTPS URLを外部ブラウザで開く。アプリが制御するWebView内で利用者データを収集する実装ではない。

## 3. データ型ごとの回答

現行実装では、以下をすべて**収集しない / 共有しない**として回答する。

| Google Playの主なデータ区分 | 回答案 | 実装根拠 |
|---|---|---|
| 位置情報 | 収集しない | 位置情報権限・APIなし |
| 個人情報 | 収集しない | 氏名、メール、住所、電話番号の入力なし |
| 財務情報 | 収集しない | 課金・決済なし |
| 健康、フィットネス | 収集しない | 該当機能なし |
| メッセージ | 収集しない | メッセージ機能なし |
| 写真、動画 | 収集しない | 写真ライブラリ・カメラを読まない |
| 音声ファイル | 収集しない | マイク・音声入力なし |
| ファイル、ドキュメント | 収集しない | 利用者ファイルの読込なし |
| カレンダー | 収集しない | 該当権限・機能なし |
| 連絡先 | 収集しない | 該当権限・機能なし |
| アプリのアクティビティ | 収集しない | 回答数等は端末内だけで保存 |
| ウェブ閲覧 | 収集しない | 外部ブラウザの閲覧履歴を取得しない |
| アプリの情報、パフォーマンス | 収集しない | クラッシュ・診断SDKなし |
| デバイスまたはその他のID | 収集しない | 広告ID、端末ID、独自利用者IDなし |

## 4. データ削除

設定画面の「データリセット」で、`hee_no_tane_save_data`キーに保存された端末内データを削除する。

削除対象:

- 回答状況
- 獲得済みカード
- 閲覧数、回答数、ストリーク
- テーマ設定
- オンボーディング完了状態

アカウントおよび開発者サーバー上の利用者データは存在しない。ストア上の説明とプライバシーポリシーでは、端末内リセットとアンインストールによる削除方法を案内する。

## 5. Play Console入力前の必須再確認

- [ ] 提出するAABのcommit SHA、versionName、versionCodeを記録した
- [ ] `pubspec.lock`を含め、第三者SDKのデータ収集仕様を確認した
- [ ] Release AABのマージ済みAndroidManifestを確認した
- [ ] Firebase、広告、分析、クラッシュ収集、通知、課金SDKが追加されていない
- [ ] 通常利用時の通信先を確認し、開発者サーバーへの送信がない
- [ ] 共有が利用者の明示操作だけで開始される
- [ ] アプリ内法務表示、公開プライバシーポリシー、Data safety回答が一致する
- [ ] Google Playの最新フォーム文言とデータ区分をPlay Console上で再確認した
- [ ] ファミリー向けプログラムへの参加有無と対象年齢を別途確定した

## 6. 変更時に回答を見直す機能

次のいずれかを追加した場合は「収集・共有なし」を再評価する。

- アカウント、クラウド同期、バックエンド
- 広告、分析、クラッシュ収集、リモート設定
- プッシュ通知
- 課金、サブスクリプション
- カメラ、写真、マイク、位置情報、連絡先
- 問い合わせフォームまたは自由入力
- オンラインAI、ユーザー投稿
