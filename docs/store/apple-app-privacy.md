# Apple App Privacy 回答案

最終更新日: 2026年7月14日
対象: `へぇのタネ` 現行MVP
状態: **App Store Connect入力前の回答案。提出するArchiveと第三者SDKを再確認すること。**

## 1. 推奨回答

App Store Connectの「App Privacy」では、現行実装を前提に次の回答を推奨する。

| 質問 | 回答案 |
|---|---|
| あなたまたは第三者パートナーは、このAppからデータを収集しますか | **いいえ** |
| App Privacy表示 | **Data Not Collected / データの収集なし** |
| トラッキング目的でデータを使用しますか | **いいえ** |
| ATTの許可要求を表示しますか | **いいえ** |

Appleは、端末内だけで処理され、端末外へ送信されないデータをApp Privacy上の「収集」とみなさないとしている。現行実装の回答状況、カード所有、統計、設定は端末内の`SharedPreferences`にのみ保存される。

## 2. 実装上の根拠

### 2.1 端末内でのみ処理するデータ

本アプリは次の情報を端末内に保存する。

- カード閲覧数
- クイズ回答数
- 連続回答日数
- 最終回答日、最終報酬日
- 日替わり問題の完了日、問題ID、カードID
- 獲得済みカードID
- テーマ設定
- オンボーディング完了状態

これらはゲーム進行またはProduct Interactionに相当し得る情報だが、開発者または第三者パートナーがアクセス可能な形で端末外へ送信しないため、現行実装では「収集なし」とする。

### 2.2 アカウント、識別子、広告、分析

現行MVPには次がない。

- アカウント、ログイン、クラウド同期
- バックエンドAPI
- 氏名、メール、電話番号等の入力
- IDFA、広告ID、独自ユーザーIDの取得
- 広告SDK
- 分析SDK
- クラッシュ収集SDK
- 課金、購入履歴
- プッシュ通知

したがって、利用者へのリンク、トラッキング、広告測定を目的とするデータ利用はない。

### 2.3 OS権限

`ios/Runner/Info.plist`には、カメラ、写真、マイク、位置情報、連絡先等の利用目的文字列がない。現行実装ではこれらの保護対象データへアクセスしない。

提出前には、Xcode Archiveに含まれるEntitlements、Privacy Manifest、第三者SDKのPrivacy Manifestも確認する。

### 2.4 カード画像の共有

利用者が共有ボタンを選択した場合、本アプリは画面から生成したPNGカード画像をOS共有シートへ渡す。

- 利用者が毎回明示的に開始する
- 共有先は利用者が選択する
- 開発者サーバーを経由しない
- 開発者は共有先、送信相手、投稿内容を受領しない
- 端末内の写真ライブラリを読み込まない

このため、開発者または統合済み第三者パートナーによる継続的なデータ収集には該当しない前提とする。共有先サービス自身のデータ取り扱いは、そのサービスのプライバシーポリシーに従う。

### 2.5 出典リンク

承認済みHTTPS出典は外部ブラウザで開く。アプリ内で制御するWebViewを使用して利用者データを収集する実装ではない。開発者は外部サイトの閲覧履歴を受領しない。

## 3. データ型ごとの確認結果

次のAppleデータ型はすべて**収集しない**として回答する。

| データ型 | 回答案 | 根拠 |
|---|---|---|
| Contact Info | 収集しない | 入力・アカウントなし |
| Health & Fitness | 収集しない | 該当機能なし |
| Financial Info | 収集しない | 課金・決済なし |
| Location | 収集しない | 位置情報API・権限なし |
| Sensitive Info | 収集しない | 該当入力なし |
| Contacts | 収集しない | 連絡先権限なし |
| User Content | 収集しない | 投稿、自由入力、写真読込なし |
| Browsing History | 収集しない | 外部ブラウザ履歴を取得しない |
| Search History | 収集しない | 検索機能なし |
| Identifiers | 収集しない | ユーザーID、端末ID、広告IDなし |
| Purchases | 収集しない | 課金なし |
| Usage Data | 収集しない | 利用統計は端末内のみ |
| Diagnostics | 収集しない | クラッシュ・性能収集SDKなし |
| Surroundings | 収集しない | 環境スキャンなし |
| Body | 収集しない | 身体トラッキングなし |
| Other Data | 収集しない | その他の端末外送信なし |

## 4. Tracking確認

現行実装では、次のいずれも行わない。

- アプリ内データと他社データの結合
- ターゲティング広告または広告測定
- データブローカーへの提供
- 複数アプリ・Webサイトをまたぐ利用者追跡
- IDFA取得

よって、Trackingは**No**、ATT許可要求は**不要**とする。

## 5. 公開リンク

App Store Connectには、一般公開され、ログイン不要で閲覧可能なプライバシーポリシーURLが必要である。

公開前に次を確定する。

- [ ] `docs/store/privacy-policy-ja.md`を公開URLへ掲載した
- [ ] App Store ConnectのPrivacy Policy URLへ登録した
- [ ] Support URLを登録した
- [ ] URLがHTTPSで、ログインなしで表示できる
- [ ] アプリ名、運営者情報、最終更新日、問い合わせ先が一致する

## 6. App Store Connect入力前の必須再確認

- [ ] 提出するArchiveのcommit SHA、Version、Buildを記録した
- [ ] `pubspec.lock`の第三者パッケージを確認した
- [ ] Xcode OrganizerでArchive内容を確認した
- [ ] Privacy ManifestとRequired Reason API申告を確認した
- [ ] Firebase、広告、分析、クラッシュ収集、通知、課金SDKがない
- [ ] 実機で通常フロー中の通信先を確認した
- [ ] カード共有は利用者の明示操作だけで開始される
- [ ] 外部リンクは外部ブラウザで開く
- [ ] アプリ内法務表示、公開プライバシーポリシー、App Privacy回答が一致する
- [ ] Appleの最新データ型と定義をApp Store Connect上で再確認した

## 7. 回答を変更すべき機能追加

次のいずれかを導入した場合は、Data Not Collectedを維持できるか再評価する。

- アカウント、バックエンド、クラウド同期
- 広告、分析、クラッシュ収集、リモート設定
- プッシュ通知
- 課金、サブスクリプション
- カメラ、写真、マイク、位置情報、連絡先
- 問い合わせフォーム、自由入力、ユーザー投稿
- オンラインAIまたは外部API
