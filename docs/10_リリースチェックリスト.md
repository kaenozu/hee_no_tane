# へぇのタネ リリースチェックリスト

最終更新日: 2026年7月12日

このチェックリストは、一般ユーザーへ配布する前に確認する項目を、コードで自動確認できるものと実機・ストア作業に分けたものです。

## 1. 自動検証

- [ ] `dart run tool/validate_content.dart` が成功する
- [ ] `dart run tool/audit_content_sources.dart` が成功する
- [ ] `dart run tool/audit_content_sources.dart --require-approved` が成功する
- [ ] `flutter analyze` が成功する
- [ ] `flutter test` が全件成功する
- [ ] `flutter build web --no-web-resources-cdn` が成功する
- [ ] `flutter build appbundle --release` が成功する
- [ ] リリースビルドにデバッグバナーが表示されない
- [ ] 問題・カードJSONに未検証項目、重複ID、参照切れがない

## 2. Android実機

- [ ] 初回起動からオンボーディング完了まで進める
- [ ] 回答、保存、カード獲得、図鑑閲覧が正常
- [ ] アプリ終了・再起動後もデータが保持される
- [ ] システムバック操作で保存中の回答が失われない
- [ ] 小型端末で文字切れや操作不能がない
- [ ] LINE、X、Google Drive等へ共有画像を渡せる
- [ ] 共有キャンセル後にエラーが表示されない
- [ ] 共有ボタン連打で複数の共有シートが開かない
- [ ] 署名済みAABをPlay Consoleの内部テストへアップロードできる

## 3. iPhone / iPad実機

- [ ] 初回起動から主要フローを完了できる
- [ ] スワイプバック中に保存状態が壊れない
- [ ] iPhoneで共有シートが正常に開く
- [ ] iPadで共有ポップオーバー位置が正常
- [ ] 共有中に画面を閉じてもクラッシュしない
- [ ] TestFlightビルドをインストールできる

## 4. Web

- [ ] Chrome、Safari、Edgeの最新安定版で主要フローを確認
- [ ] Web Share API対応環境で共有できる
- [ ] 非対応環境でPNGダウンロードへフォールバックする
- [ ] 生成ファイル名が`hee_card_<card-id>.png`になる
- [ ] 画面幅320px程度でも主要操作ができる
- [ ] ホスティング環境でリロード時に404にならない

## 5. コンテンツ品質

- [ ] 全問題を人手で読み、正答と説明が一致している
- [ ] 全問題・カードに構造化された`source`情報がある
- [ ] 出典の正式名称、発行元、URL、確認日が記録されている
- [ ] `reviewStatus: approved`の項目だけがリリース対象になっている
- [ ] 問題と関連カードの承認済み出典URLが一致している
- [ ] 数値・ランキング・現職者など変化する情報に確認日がある
- [ ] 医療、法律、投資分野で断定的な助言をしていない
- [ ] 不適切表現、誤字、表示切れがない
- [ ] 画像・フォント・文章の利用権を確認済み

## 6. ストア掲載

- [ ] アプリ名、短い説明、詳細説明を確定
- [ ] アイコンとスクリーンショットを各端末サイズで用意
- [ ] プライバシーポリシーを公開URLへ掲載
- [ ] サポートURLまたは問い合わせ先を掲載
- [ ] Google Play Data safetyを実装内容と一致させる
- [ ] App StoreのApp Privacy回答を実装内容と一致させる
- [ ] 年齢区分をコンテンツに合わせて回答
- [ ] バージョン番号とビルド番号を更新
- [ ] リリースノートを用意

## 7. リリース判定

次の条件をすべて満たすまで一般公開しない。

- CIが全件成功
- `audit_content_sources.dart --require-approved`が成功
- Androidの主要フローと共有が実機で成功
- iOS/iPadOSの主要フローと共有が実機で成功
- Web主要ブラウザで重大な不具合がない
- 全コンテンツの人手確認が完了
- プライバシーポリシー、サポート情報、ストア開示が一致
- P0/P1の既知クラッシュまたはデータ消失不具合が0件
