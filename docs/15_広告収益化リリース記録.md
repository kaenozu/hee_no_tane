# 広告収益化リリース記録

この文書は、広告コードの実装状態と、AdMob / Play Console の管理画面で行う作業を分離して記録するためのチェックリストです。秘密値や本番アカウント情報はリポジトリへ保存しません。

## コード実装（このリポジトリで検証する範囲）

- Google Mobile Ads の初期化は UMP 同意フロー後に行う。
- UMP の更新・フォーム・`canRequestAds` の失敗は広告だけを無効化し、クイズと保存データの起動を妨げない。
- 同意情報の応答がない場合も5秒で広告を無効化してコア機能を開く。
- バナーはホームの統計と今日の問題の間に配置し、操作部・下部ナビゲーションへ重ねない。
- バナーのロード失敗時は枠を表示せず、ロード済み広告はWidget破棄時に解放する。
- 開発・テスト用IDは `lib/monetization/ad_config.dart` と各プラットフォーム設定にあるGoogle公式テストIDを使う。

次の項目は管理者がAdMobまたはPlay Consoleで実施し、実施日・担当者・ビルド番号をリリース判定資料へ記録する。値そのものはこのリポジトリへ書かない。

- [ ] AdMobアプリ（Android / iOS）を作成し、App IDをコードの対象環境と照合
- [ ] バナー広告ユニットを作成し、ユニットIDを対象環境と照合
- [ ] UMPの同意メッセージ、地域設定、プライバシーURLを確認

- [ ] 署名済み internal-test buildを配布し、同意あり・同意なし・広告ロード失敗で動作確認
- [ ] AdMob管理画面の本番配信設定、支払い設定、実売上はコード検証と別記録
