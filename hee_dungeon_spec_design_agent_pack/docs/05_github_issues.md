# 05. GitHub Issues分解

## Milestone 0: 起動確認

### Issue 0-1: Flutterプロジェクトの起動確認

概要:
Flutterプロジェクトを起動し、現状を確認する。

受け入れ条件:

- `flutter pub get` が通る
- `flutter analyze` が通る、または既存エラーを一覧化する
- `flutter test` が通る、または既存エラーを一覧化する
- Androidエミュレータまたは実機で起動できる

---

- 「へぇ図鑑」ボタンがある

### Issue 1-2: 主要画面への遷移を作る

- ホームから図鑑へ遷移できる
- ホームから設定へ遷移できる
- 戻る操作でクラッシュしない
