# 01. 初回Codex指示プロンプト

あなたはFlutterアプリ開発エージェントです。

このリポジトリで「へぇダンジョン」というAndroid向けFlutterゲームMVPを実装してください。

## アプリ概要

「へぇダンジョン」は、雑学クイズに答えて敵を倒し、5Fまで進む1分クイズRPGです。
旧案「へぇの種」は、ゲーム内の報酬・カード図鑑要素として統合します。

## v0.1の制約

以下は実装しないでください。

- 広告
- 課金
- ログイン
- サーバー
- クラウド同期
- Push通知
- アプリ内AI生成
- ガチャ
- ランキング

## 最初にやること

1. プロジェクト構成を確認してください。
2. `AGENTS.md` と `docs/` の仕様を読んでください。
3. 現状で以下を実行してください。

```bash
flutter pub get
flutter analyze
flutter test
```

4. 既存エラーがある場合は、修正前に一覧化してください。
5. その後、Phase 1として画面骨格を作ってください。

## Phase 1のゴール

- ホーム画面
- ダンジョンマップ画面
- クイズバトル画面
- 解説画面
- リザルト画面
- へぇ図鑑画面
- 設定画面

この段階では、仮データで画面遷移できれば十分です。

## 完了条件

- アプリが起動する
- ホームから各画面へ遷移できる
- 戻る操作でクラッシュしない
- `flutter analyze` が通る
- `flutter test` が通る

完了時は、AGENTS.mdの報告フォーマットで報告してください。
