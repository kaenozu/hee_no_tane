# 05. Review Prompt

このリポジトリの現在のへぇダンジョン実装をレビューしてください。

## 確認観点

- 仕様書に反した実装がないか
- v0.1で禁止している広告、課金、サーバー、ログイン、アプリ内AI生成が入っていないか
- verified falseの問題が出題されないか
- BattleServiceにロジックが集約されているか
- Widgetにビジネスロジックが入りすぎていないか
- セーブデータが壊れやすくないか
- flutter analyze / flutter test が通るか
- 1プレイ完走できるか

## 出力

重大度別に出してください。

- Blocker
- High
- Medium
- Low

各指摘には、対象ファイル、問題内容、修正案を含めてください。
